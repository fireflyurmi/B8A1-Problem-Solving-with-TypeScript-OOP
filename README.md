# 🚀 TypeScript & OOP Assignment

A practical assignment focused on TypeScript fundamentals, problem-solving, and Object-Oriented Programming (OOP). This project demonstrates my understanding of TypeScript through 8 coding problems and 2 technical blog posts.

## 📌 Assignment Overview

This assignment consists of two main parts:

### 💻 Part 1: Problem Solving (8 Problems)

Implemented 8 problems using TypeScript to demonstrate the following concepts:

| Problem | Topic | Concepts Covered |
|---|---|---|
| 01 | Default Parameters | Default function parameters |
| 02 | Union Types | Union types and type narrowing |
| 03 | Readonly Tuples | Tuple types and readonly |
| 04 | Generics | Generic functions and arrays |
| 05 | Interfaces | Interfaces, filtering, and array methods |
| 06 | Keyof & Generics | Generic constraints and property extraction |
| 07 | OOP | Classes, inheritance, and access modifiers |
| 08 | Asynchronous Programming | Promises, resolve, reject, and setTimeout |
